Place Face API model files here, e.g.:
- tiny_face_detector_model-weights_manifest.json / .bin
- face_landmark_68_model-weights_manifest.json / .bin
- face_recognition_model-weights_manifest.json / .bin

You can obtain weights from the official face-api.js model repository or any reliable mirror.
Ensure the folder structure is exactly `assets/models` so the app can load them.
